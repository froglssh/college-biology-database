# 03 生物化學與分子生理庫 (Biochemistry & Molecular Physiology Database)

本庫整合了資料夾中頂級生物化學教科書與生理專題專著：
1. **王鏡岩/朱聖庚/徐長法《生物化學》(第五版)** (11.7 MB)：華人高校權威生化巨著，涵蓋蛋白質物理化學、酵素動力學、糖代謝、脂代謝、生物氧化、核酸代謝與基因表現分子機轉。
2. **生殖生物學（簡體版）** (9.6 MB)：配子發生、受精卵裂、性別決定、胚胎植入與下視丘-垂體-性腺軸。
3. **Under the Knife** (0.3 MB)：解剖學與外科生理學專論。

## 本庫檔案清單與功能

- [`酵素動力學與受質抑制常數精解.md`](./酵素動力學與受質抑制常數精解.md)：Michaelis-Menten 方程數學推導、米氏常數 $K_m$ 與催化常數 $k_{\text{cat}}$ 物理意義、競爭型/非競爭型/反競爭型抑制劑雙倒數作圖對比。
- [`代謝途徑化學反應與能量計量全解.md`](./代謝途徑化學反應與能量計量全解.md)：糖酵解 10 步酶促反應式、三羧酸循環 (TCA) 碳流與受質水平磷酸化、氧化磷酸化呼吸鏈複合物、P/O 比與 ATP 理論產量嚴格核算。
- [`生殖內分泌與胚胎誘導機制.md`](./生殖內分泌與胚胎誘導機制.md)：精子頂體反應、快慢多精入卵阻斷機制、Spemann-Mangold 胚胎組織者誘導、LH/FSH 與雌激素/黃體素月經週期反饋迴路。
