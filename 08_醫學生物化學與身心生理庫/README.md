# 08 醫學生物化學與身心生理庫 (Medical Biochemistry & Psychoneurobiology Database)

本庫整合了典藏於 `網路圖書/生物學` 中的美國醫學執照考試聖經、圖解醫學生化與身心健康心理學巨著：
1. **BRS Biochemistry, Molecular Biology, and Genetics (Board Review Series)** (20.8 MB)
2. **Medical Biochemistry at a Glance** (27.1 MB)
3. **Health Psychology (10th Ed - Shelley E. Taylor)** (6.6 MB)
4. **Health Psychology: A Biopsychosocial Approach (4th Ed - Richard O. Straub)** (17.2 MB)

## 本庫檔案清單與功能

- [`BRS_醫學生物化學與遺傳代謝缺陷.md`](./BRS_醫學生物化學與遺傳代謝缺陷.md)：USMLE 醫學高頻考點精煉，剖析苯酮尿症 (PKU)、半乳糖血症、肝醣儲積症 (von Gierke 病)、血紅素鐮形血球與地中海貧血之分子病理學。
- [`壓力與神經內分泌HPA軸身心生理.md`](./壓力與神經內分泌HPA軸身心生理.md)：Shelley Taylor 經典身心醫學模型，解構急性壓力 SAM 軸（交感-腎上腺髓質）與慢性壓力 HPA 軸（下視丘-垂體-腎上腺皮質皮質醇），深入心理神經免疫學 (PNI) 之免疫抑制機轉。
