# 09 真菌學與生態百科辭典庫 (Mycology & Ecological Lexicon Database)

本庫整合了典藏於 `網路圖書/生物學` 中的真菌生物學專論與權威辭典手冊：
1. **Fungi: Biology and Applications (Kevin Kavanagh)** (5.1 MB)：真菌細胞構造、菌絲頂端生長機制、真菌次級代謝產物（抗生素、免疫抑制劑）、病原真菌與抗真菌藥物靶點、環境生物降解。
2. **Plant Biology.pdf** (3.4 MB)：植物生理與形態專題。
3. **ECOLOGICAL DICTIONARY.pdf** (9.2 MB)：生態學權威專業辭典。
4. **Encyclopedia of Biology (Don Rittner & Timothy L. McCabe)** (7.0 MB)：全方位生命科學名詞百科全書。

## 本庫檔案清單與功能

- [`真菌生物學與次級代謝應用.md`](./真菌生物學與次級代謝應用.md)：Kevin Kavanagh 經典真菌學，解析幾丁質細胞壁、麥角固醇 (Ergosterol) 作為抗真菌藥物靶點、青黴素與環孢素生化合成、菌根共生 network。
- [`生態學與生命科學百科辭典速查.md`](./生態學與生命科學百科辭典速查.md)：精選生態學詞典與生物百科中數百條關鍵詞條速查索引（從 Allee 效應、生質能、生物累積到群集穩定性）。
